PROJECT REPORT
FORECASTING PM10 AND PM2.5 WITH DEEP LEARNING

1. TITLE AND GOAL

Forecasting PM10 and PM2.5 with deep learning, plus the PM2.5/PM10
cross-pollutant relationship.

The experiments compare a persistence baseline with five pooled deep-learning
models: LSTM, TCN, 1D-CNN, Model A (multi-scale attention TCN), and Model B
(BiLSTM with attention and gating). Every learned model predicts PM10 and
PM2.5 jointly. The goal is to compare saved test metrics under shared data
preparation, not to claim that correlation is causal.

PROJECT WORKFLOW AND ACHIEVEMENTS

- EDA.ipynb explored and cleaned the multi-station hourly data. 02_LSTM.ipynb
  trained the LSTM and generated persistence results. 03_TCN_CNN_Comparison.ipynb
  trained and compared the TCN and 1D-CNN with the LSTM and persistence.
- 04_EBAMTN_Components.ipynb implemented and trained Model A. It includes
  reusable, resumable training/evaluation code and Model A result files.
- 05_ModelB_BiLSTM_Attention.ipynb implemented Model B using the shared Model A
  data and training helpers. Model B completed all three forecast horizons;
  weights, metrics, predictions, training summaries, and loss plots were saved.
- The Model B comparison cell initially stopped on a misspelled index argument
  (Falssae). That typo was corrected to False and the comparison cell was run
  again. The corrected run produced the combined comparison CSV, RMSE
  improvement CSV, charts, and training/parameter table; it did not retrain
  Model B.
- The work implements two components inspired by EBAMTN, not the paper's full
  model. Saved evaluations include pooled test comparisons and per-station
  metrics.

TRAINING AND EVALUATION

- The LSTM, TCN, and 1D-CNN notebooks use Adam, learning rate 1e-3, MSE loss,
  batch size 256, epoch limit 50, dropout 0.2, ReduceLROnPlateau with factor
  0.5 and scheduler patience 3, and early-stopping patience 8.
- Model A and Model B retain the shared data splits, lookback, horizons,
  batch size, epoch limit, learning rate, and seed. They use dropout 0.1,
  weight decay 1e-4, gradient clipping at 1.0, MSE, and the same scheduler
  and early-stop patience settings.
- Metrics are MAE, RMSE, and R2 in original concentration scale, both pooled
  and per station. Persistence means carrying the last observed value of each
  pollutant forward unchanged to the forecast target time.

4. BASELINE AND THE THREE STANDARD MODELS

PERSISTENCE

Persistence is a non-trained baseline: the latest observed PM10 and PM2.5
values are used as their forecasts. It has no learned parameters, training
time, or best epoch. Its metrics are included in the LSTM metrics file and
comparison charts.

LSTM

The pooled LSTM consumes the shared feature sequence and uses the final LSTM
time-step output in a two-output linear head. The notebook configures hidden
size 64, two LSTM layers, and dropout 0.2.

TCN

The pooled TCN uses five residual blocks with 64 channels, kernel size 3,
dilations 1, 2, 4, 8, and 16, two causal convolution layers per block,
BatchNorm, ReLU, dropout, and residual projections where needed. It reads the
last sequence output through a two-output linear head.

1D-CNN

The 1D-CNN uses three kernel-size-3 Conv1d layers with channels 32, 64, and
64. Each layer has BatchNorm, ReLU, and dropout; global average pooling feeds
the two-output linear head.

5. THE TWO RESEARCH-PAPER MODELS

The project notebooks and research notes refer to Xie et al. (2025) and
EBAMTN Algorithms 1 and 2. This work is component-level, not a reproduction
of the full EBAMTN. Both components have saved code, weights, metrics, and
figures.

MODEL A: MULTI-SCALE ATTENTION TCN

Three parallel causal Conv1d branches use kernel sizes 3, 5, and 7, with
32, 64, and 128 output channels. BatchNorm, ReLU, and dropout follow each
convolution. Each branch is projected to 64 fused channels; branch-specific
linear scores from global-average-pooled descriptors are softmaxed and used
to weight the summed branch outputs.

The dilated stack uses 64 channels, kernel size 3, BatchNorm, ReLU, dropout,
and 1x1 skip projections. The saved implementation uses dilations 1, 2, 4,
8, and 16; the notebook reports a receptive field of 69, covering the
48-step lookback. The last stack time step feeds a 64-unit head and a
two-output linear layer.

Model A has 118,661 trainable parameters. Its saved CPU run summary reports:

MODEL B: BILSTM WITH MULTI-HEAD ATTENTION AND GATING

Model B uses a two-layer bidirectional LSTM with 64 hidden units per
direction, four-head self-attention with Q=K=V, and a sigmoid gate that mixes
the BiLSTM and attention outputs. The block projects to 64 features; the last
time step feeds a 64-unit head and two outputs. The bidirectional encoder
processes only the observed input window. Model B has 250,754 trainable
parameters.

The project brief identifies the source as Xie, Chow, Chuah and Raymond
(2025), "Multi-pollutant air quality forecasting using bidirectional attention
and multi-scale temporal networks", Frontiers in Environmental Science
13:1623630, DOI 10.3389/fenvs.2025.1623630. The brief describes the paper's
results as R2 above 0.94 for one-step forecasts using one site per city,
168-hour inputs of PM2.5 and PM10 only, and rows with missing values removed.
Those paper details were supplied in the project brief and were not
independently verified from a local paper copy. They are NOT directly
comparable with this project: this project uses 48-hour inputs, 21 pooled
stations, additional weather/time features, joint train-only scaling, and
different chronological evaluation windows.

7. COMPARISON AND DISCUSSION

- By pooled test RMSE, Model A is best for PM10 at H=1 and H=24, while TCN
  is best at H=6. Their reductions versus persistence are 10.5%, 5.3%, and
  29.0% at H=1, H=24, and H=6 respectively. Persistence still has the
  lowest PM10 MAE at H=24.
- For PM2.5, Model A is best by RMSE at H=1 and H=6; at H=6 its RMSE is
  6.437 versus 6.439 for TCN, a very small difference. LSTM is best by RMSE
  at H=24. The reductions versus persistence are 9.7%, 31.3%, and 3.1%.
  Persistence has the lowest PM2.5 MAE at H=24.
- Model B wins PM2.5 MAE at H=1 (1.965 versus 1.975 for LSTM), but Model A
  has lower PM2.5 RMSE and higher R2 at that horizon. Model B does not have
  the best pooled RMSE at any target/horizon. Relative to persistence, Model
  B's RMSE improvement ranges from 1.2% to 22.2% for PM10, and from -1.2%
  to 26.9% for PM2.5; its PM2.5 H=24 RMSE is worse than persistence.
- Model A versus the plain TCN is mixed. Model A has slightly lower RMSE for
  both targets at H=1, PM10 is slightly worse at H=6, PM2.5 is nearly tied
  at H=6, and Model A is lower for both at H=24. Model A has 118,661
  parameters versus 115,778 for TCN; Model B has 250,754. The measured
  performance does not show a consistent accuracy gain from the larger
  attention-gated BiLSTM.
- H=6 provides the clearest improvements over persistence. At H=24, some
  methods are close to or worse than persistence, and persistence has the
  lowest MAE for both pollutants. Accuracy does not improve monotonically
  with model complexity.
- Model A's best epochs were early at H=6 and H=24; Model B's best epochs
  were 6 of 14 at H=6 and H=24, but 26 of 34 at H=1. These indicate early
  stopping for some runs, not by themselves overfitting. Loss plots are
  available, but a consistent numeric train/validation-gap table was not
  saved for every model, so overfitting conclusions are limited.
- TCN and 1D-CNN training times are model-total execution/resume figures;
  previously interrupted time was not recorded. Model A/B timings are
  per-horizon logs. These different recording scopes do not support a clean
  speed ranking. LSTM training time is NOT AVAILABLE / NOT RECORDED.
- The Model B comparison-cell typo caused a NameError before the comparison
  CSV write. After changing the argument to False, the comparison cell
  completed and saved its outputs. The training artifacts were already on
  disk and did not need to be recreated.
- EDA shows a PM2.5-PM10 correlation of 0.911, and the models use both
  pollutants as inputs and jointly predict both. No PM10-as-input ablation
  isolates the value of cross-pollutant information.
- Wind direction was not included, only seed 42 is saved, and no
  hyperparameter-tuning sweep is present. These limit generalization and
  attribution claims.

8. CONCLUSION

By pooled test RMSE, Model A is best for PM10 at H=1 and H=24, and TCN is
best at H=6; for PM2.5, Model A is best at H=1 and nearly tied with TCN at
H=6, while LSTM is best at H=24. Model B has the lowest PM2.5 MAE at H=1,
but does not win on pooled RMSE. H=6 gives the strongest RMSE reductions
over persistence, while persistence has the lowest MAE for both pollutants
at H=24. Model A improves on plain TCN in some settings but not all, and the
larger Model B does not consistently improve accuracy. The evaluation covers
about 19 months of hourly data, with a September-to-December test period,
one seed, no tuning sweep, train-only station scaling, short-gap
interpolation, and no wind-direction feature. Because both pollutants are
inputs and outputs, these results do not isolate the causal value of
cross-pollutant information or establish broad generalization.
